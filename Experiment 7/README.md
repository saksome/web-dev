# Experiment 7 — React Notes App

A single-page notes application built with React and Vite. It supports creating, viewing, editing, searching, pinning, and deleting notes.

## Features

- Create, read, update, and delete notes (CRUD)
- Search notes by title and description
- Pin important notes to the top
- Choose a colour for each note
- Save notes in the browser using localStorage
- Responsive layout for desktop and mobile screens
- Delete confirmation and feedback messages

## Run locally

Requirements: Node.js and npm.

1. Open a terminal in the Experiment 7 folder.
2. Run npm install.
3. Run npm run dev.
4. Open the local URL printed in the terminal, commonly http://localhost:5173.

To check a production build, run npm run build.

## Storage

Notes are stored in the current browser's localStorage. They do not sync across devices and no backend is used.
